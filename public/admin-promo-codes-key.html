Generate a new key

Do this in a browser on the VDI that runs the daily upload, then save the file there. Generating a new key immediately stops the old one working (the QC relay is not affected).

Never paste the key into Slack, email or any chat. It is shown once, on this screen only.
  1. Save the downloaded file as promo-codes-secret (no extension).
  2. Move it to C:\Users\<you>\.qc-relay\promo-codes-secret on the VDI.
  3. Close this page — the key cannot be shown again.
