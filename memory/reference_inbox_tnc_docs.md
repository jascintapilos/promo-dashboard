## QPRO / QP2 Inbox T&C Reference
**URL:** https://docs.google.com/document/d/1iqUhvE-9rsPsueBBXDy7ymiHbJpT480W2AeFW4WdvSQ/edit

Deposit Bonus format (confirmed 2026-06-17):
- Table: 2 columns (Min Deposit | Bonus Percentage), second row = "Bonus play condition: Xx turnover"
- Bullet list: Bonus Condition Example (deposit / bonus / total / turnover)
- T&C: 8 clauses
  1. Min deposit + max bonus
  2. Turnover requirement (written out e.g. "ten (10) times")
  3. Each member can claim only once
  4. Eligible game categories (positive + exclusion in brackets)
  5. Claimed within X days, bonus expires X days after claim
  6. Promo codes time-limited, cannot be extended once expired
  7. Refresh button reminder
  8. General :brandname Terms and Conditions apply.
- No anti-abuse wall, no multi-account clause in body (covered by footer)

## WS1 / WS2 (IGMP / MB8) Inbox T&C Reference
**URL:** https://docs.google.com/document/d/1et85maHn3VOo1VSkc9Us2dhaSzA4CEk54gmE9R_BC9Y/edit

Deposit Bonus format:
- Table: 3 columns (Min Deposit | Max Bonus | Turnover)
- T&C: 5 clauses only (much shorter than QPRO/QP2)
  1. Bonuses valid for X days upon issuance
  2. Each member can claim only once
  3. Valid across all game categories (excluding Blackjack and Virtual Sports)
  4. Promo codes time-limited, cannot be extended
  5. General [brandname](url) terms and conditions apply. (hyperlinked, not :brandname placeholder)
- No bonus condition example block
- No Refresh button clause
