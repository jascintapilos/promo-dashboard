**WS1/IGMP does NOT have a message template (MT) system** like QPRO/QP2.

For FC promos on WS1:
- T&C content (bilingual intro, stats table, numbered clauses) is stored in `PromotionRewardContents` directly on the promo record.
- Subject line is the `PromotionRewardName` field within the content row.
- Auto-generated by `src/igmp-tnc.js` → `buildTncRow()` → `buildAddFreeCredit()`.

**Don't confuse with QPRO/QP2:** Those platforms use a separate MT record linked via template_code. WS1 has no such linkage.

**Inbox (NM module)** is a separate system entirely (Notification Manager on IGMP). Inbox messages for WS1 promos are sent manually — not automated.

**Why:** Mid-session confusion caused incorrect assumptions about MT creation. WS1 T&C lives in the promo itself, full stop.
